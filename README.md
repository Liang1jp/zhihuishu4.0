# [fxxkZhiHuiShuMeow] Sonamiの智慧树智慧课程刷课脚本(这里是由凉更新的4.0版本喵)
（4.0版本主要加了对于共享课的自动刷课）
## 前置依赖

需要 Windows 和 Python 3.11+（安装 Python 时勾选 “Add Python to PATH”）。默认使用系统自带的 Edge，不需要额外下载浏览器。

首次运行 `run.bat` 会自动检查并安装 `script/requirements.txt` 里的 Playwright；如果自动安装失败，再手动执行：

```powershell
python -m pip install -r script/requirements.txt
```

## 运行

双击根目录的 `run.bat` 会打开界面（UI），在项目根目录执行 `.\run.bat` 也一样。

带参数时仍然走原来的命令行，比如只处理指定翻转课（把 `12345678` 换成你的课程 ID）：

```powershell
.\run.bat --flip-course 12345678
```

第一次运行需要在打开的浏览器里用 `知到APP` 扫码登录；之后会免登录**直接登入**。想登出用：

```powershell
python script/run.py --fresh-login
```

**⚠WARNING 不要同时运行多个脚本 ⚠**

## 界面（UI）

界面分四块：

1. **DeepSeek 官方 API**：填 API Key（默认 `https://api.deepseek.com`、模型 `deepseek-chat`），点“保存”写入 `script/config.json`，点“测试”验证连通。
2. **课程表**：点“读取课程”后列出智慧课程 + 翻转课；点击“刷课 / 测验作业”两列切换勾选。旁边的“课程核对”会额外打印每门课的 `courseType` 与分类，用来排查“某门课没被识别到”。
3. **共享课（老平台）**：界面第二行有三个按钮，按 ①②③ 顺序操作（见下方“共享课”一节）。
4. **作业 / 测验表**：给勾了“测验作业”的课程点“读取作业/测验”，会列出作业和章测试；勾选要处理的条目。
5. **日志**：实时输出。

- “开始刷课”只处理课程表里勾了“刷课”的课；
- 课程按 `courseType` 分类显示：`0/1` = 智慧课程（本脚本可刷），`2` = 共享课，其他 = AI 课程；
- 共享课 / AI 课程会照常列出（不再被悄悄丢掉），但它们走的是另一个平台的接口，本脚本只识别、不代刷，勾选时也会提示；
- `newFlag` 为 `0` 的课在网页上会跳到 AI 页面，同样不在本脚本处理的接口里；
- “AI 答题（选中）”只处理作业表里勾选的条目：抓题 → DeepSeek 出答案 → **弹出确认窗口，点“确认提交”才会提交，点“取消”不提交**；
- AI 目前只自动做客观题（单选 / 多选 / 判断），简答、论述、作文会跳过并写进日志；
- 带人脸识别 / 身份验证的正式考试会自动跳过，不做绕过；
- 只勾你想处理的条目，不勾的不会动。

> `script/config.json` 里是 API Key，**打包发送前请删掉**；`script/.session`（登录缓存）和 `script/output`（运行报告）也是本机数据，不要一起发出去。

## 共享课（老平台）

智慧树的「共享课」不在智慧课程平台上，而在 `studyvideoh5.zhihuishu.com`（我的学堂），
接口体是加密的（`secretStr=...`），所以脚本**不在服务端伪造请求**，而是驱动页面自己播放、
由页面自己的加密通道上报——参数和真人操作完全一致。

### 三步操作

1. **① 识别我的共享课** —— 打开学生首页（`onlineweb.zhihuishu.com/onlinestuh5`），
   从页面自己发出的接口响应里读出课程清单，再用平台自己的编码算法还原成可播放网址。
   结果存到 `script/output/shared-courses-*.json`，日志里会列出课程名和网址。
2. **② 选择要刷的课** —— 从识别结果里勾选，选中项存进 `script/config.json` 的 `shared_urls`。
3. **③ 开始刷** —— 依次处理选中的课，会问你是每门试跑 1 节还是跑完全部。

> 识别不出课程时，多半是首页还在加载。重跑时可加大等待：命令行
> `python script\shared_courses.py --wait 90`。

### 刷课行为

- 引擎用 `queryStuyInfo` 的 `watchState` 判断完成（`1` = 完成），服务端不认就记 `not_confirmed`；
- 倍速默认 **1.5x**，且每节在 `1.2 ~ 上限` 之间随机，不再是恒定 2.0x；
- 老平台按**累计播放秒数**计时，跳进度条无效；
- 每门课首屏默认等 45 秒（`--wait` 可调）；
- 遇到防挂机弹题会**自动作答**，作答前会随机"思考" 4~15 秒；答案来源按可信度排序：
  1. 服务端回包里的 `zAnswer`（已答过的题才有）；
  2. 选项自带的 `result == "1"` 标记（单选题里恰有一个，实测与 `zAnswer` 一致）；
  3. 前两者都没有时，交给 DeepSeek 判断（需在界面里配好 API Key）。
  答不出来就停下并记进报告，不会乱选；
- 报告写在 `script/output/shared-learn-*.json`，按课程分组。

> 待补时长由服务端决定：课程越多、已学越少，需要的时间越长（一门 12.9 小时的课按 1.5x
> 算约 6 小时）。这是平台规则，不是脚本慢。

### 降低被判定异常的概率

脚本只是把重复操作自动化，**无法保证平台不识别**。以下是已经做的伪装，以及建议的使用方式：

已做的：

- 抹掉 `navigator.webdriver` 与 `--enable-automation`（`--no-stealth` 可关闭）；
- 用真实鼠标轨迹点击节次，不是页面内 JS `click()`；
- 倍速每节随机；弹题作答前随机停 4~15 秒；节与节之间随机停顿 1.5~6 秒。

建议的：

- **分段跑**：加 `--max-units 10`，跑 10 节就收工，隔几小时再跑剩下的，别一次挂 8 小时；
- **别在深夜整点开始、别让人一直不在电脑前**：窗口保持可见、别最小化；
- 弹题如果能手动答，就关掉自动（`--no-quiz-auto`），错误率更低；
- 先把一门课的 1 节试通，再决定要不要跑全部。

> 平台有 `cheat/exceptionActionDetail` 这类检测接口，判定异常的后果（进度清零、记录异常）
> 需要你自己承担。这部分我给不了保证。

## 命令行刷课

不带参数时按原来的方式自动刷课，结果写到 `script/output/*.json`：

- 智慧课程：知识点目录 → 组件列表 → 视频按 10 秒一批上报、文档直接标记完成，写后读回核验；
- 翻转课：视频按 30 秒一批上报 `saveStuStudyRecord`，文档调用 `stuViewFile`，写后读回核验；
- 只放行白名单接口，写入失败不自动重试，不能确认就记 `not_confirmed`。

压缩包（zip/rar）网页只提供下载，脚本不猜它的完成方式，会留在“未完成”计数里。

只处理指定翻转课（课程 ID 或 `studyResource` 网址，可重复）：

```powershell
python script/run.py --flip-course 12345678
```

跳过翻转课只刷智慧课程：

```powershell
python script/run.py --no-flip
```
